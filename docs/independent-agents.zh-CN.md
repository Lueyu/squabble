# 我的股友与自动团队

第一次使用，只需完成三件事：**导入持仓 → 认识股友 → 创建自己的团队**。有具体问题时，再打开研究室。

## 从持仓开始

在首页完成持仓和现金确认。创建团队时，系统先展示持仓、现金与快照时间；缺少必要信息会引导补齐。开盘价优先取实时行情，取不到时直接用持仓页记录的最新价并标记延迟，不会因此卡住创建。确认后的副本是模拟盘起点，此后实盘变化不会覆盖模拟账本。

## 认识股友

打开“我的股友”。先连接一次自己的模型服务或已安装的本地助手，其他股友可复用连接。保存并检查模型连接会发送一次短请求，可能产生服务商费用；添加股友不会调用模型。

推荐股友包括财报、估值、反方、风控和主持。每位股友有独立身份、可选择的动物头像、专长和版本，可以加入多个团队；共用模型连接不会把两位股友合并。编辑器中的“工作指令”和“回答偏好”会用于实际研究，英文界面创建的推荐股友保存英文模板。名字、简介和头像属于身份元数据，单独修改不生成能力版本；工作指令、偏好、执行连接或高级资料/工具范围变化才生成新版本。已发布团队继续固定原能力版本，直到明确更新。

名册、团队选员和研究选员展示同一位股友。新会话和新团队委托固定当时的名字、头像与能力版本；以后修改身份不会重写已有会话或委托。缺少头像的历史快照保留原岗位回退。

个人聊天、不同团队和不同研究会话的记忆分别保存。可手动记下一条偏好，或明确选择某条内容分享给已有团队。分享保留来源，不能解除原资料的权限、版本或删除限制。资料范围是权限上限，不能代替资料本身、团队和本次工作的授权。

归档后不能再选择该股友或发起新的付费步骤。已经派发的工作仍可在原版本和剩余有效权限内结算；暂停团队、撤销来源或连接权限仍会阻止迟到发布或应用。历史记录保留。

## 创建自己的团队

“新建团队”采用三步引导：

1. 保留推荐协作方式，给团队命名。
2. 从已有股友中选择成员。默认按推荐模板选好财报、反方和主持；估值、防守、全面等成员模板一键换组，也可以随时自己勾选调整。
3. 核对持仓副本、主市场、预算和运行授权，然后启动。

默认每轮最多8次调用、每日16次、每月320次；每轮金额上限为日预算的一半，月度金额为日预算的20倍。现有账户和全局预算仍有效，系统不扩大这些权限。更大的团队可能需要更高的既有调用额度。

启动授权包括自动研究、系统采纳，以及在账户风险规则内替换模拟组合和进行模拟交易。每个周期复核团队版本、账户绑定、授权、交易日和预算。未满足条件会停下并显示处理入口。收盘后一小时是研究窗口，实际模拟执行还要遵守每个标的交易时段、报价、资金和账户规则。

团队首页显示运行状态、最近做了什么、成员、预算和模拟账户。可以随时“暂停团队”；暂停停止后续研究及全部自动模拟交易，包括保护单。在途任务保留真实取消、未知或结算状态。调整成员、版本或权限后，可能需要重新确认。

启动前的可编辑表单在当前浏览器标签页保留，刷新或去添加股友后可继续，并按工作区身份分开。网络中断时保留原始请求 key 与确切请求内容，使用“恢复创建进度”核对后继续。已确认结果的过时流程可以结束，保留已创建的团队、账户和回执；未知操作要先解决，不能清空后另建。旧版未区分身份的缓存逐项经过所属用户 API 校验后才展示；缓存本身不提供服务端权限。高级组织画布、关系、资料授权和手动委托仍可使用；旧岗位可在属性面板关联已有股友，或保存为独立股友，再发布新版本。转换不会复制团队私有历史。

## 需要研究问题时

在股友卡片点击“聊一聊”，或打开研究室选择一个或多个股友。空会话展示真实选中的成员。单人直接回答；多人有一位主持收束并明确结束。已有讨论固定成员版本，后续追问不会悄悄换成另一套推荐成员。团队运行记录进入该团队的委托历史；预算上限与实际支出分别展示。

“投资总览”（`/`）用于比较账户表现，“持仓”（`/holdings?accountId=real|id`）是独立一级入口，管理所选账本。“模拟账户”（`/paper`）与独立股友分开。导入保存后可继续认识股友；开始研究仍需单独明确操作。

## 外部助手与运行分析

“连接外部助手”读取真实 A2A Agent Card，再把连接登记为股友。当前支持 A2A 1.0 JSON-RPC 的发送、查询和取消；不支持流式、推送、远程交互续答或下载 URL 产物。外部模型、工具、内部记忆和费用可能不可见，未知项保持未知。加入团队需要结构化交付实际验证；能力卡的声明不能代替验证。

本地端点还需要部署方在 `A2A_LOCAL_SERVICES_JSON` 中分别登记精确的能力卡与 RPC 地址，并由用户明确允许。公网端点采用受限地址检查，不跟随任意重定向，也不向不同来源转交凭据。

运行分析可以按股友、版本、团队、团队版本、委托、工作项和尝试筛选。同一模型下的不同股友分别统计；配置模型与真实观测模型区分。历史数据无法可靠归属的部分显示未知。导出仅含安全元数据，不含提示词、回答、持仓或密钥。

当前没有自动 RSI、自改提示词或 RL 训练。独立身份、不可变版本、工作轨迹和人工反馈为后续离线评估与个体 Agent 优化保留扩展点。

实现与验证边界见[验证记录](independent-agents-validation.md)和[本轮 UI 整改验证](ui-regression-repair-validation.md)。
