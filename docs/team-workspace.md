# 团队模拟盘

首页保留已有账户曲线和入口。「我的账户」中的实仓与每个模拟账户都进入「资产与账户」，URL 的 accountId 决定当前持仓、现金和交易账本。模拟盘不允许手工编辑真实持仓；缺少报价显示未知，已保存估值注明时间，不补成零。

## 开始使用

服务端设置 `TEAM_WORKSPACE_ENABLED=true` 开放组织编辑，`TEAM_RESEARCH_ENABLED=true` 开放新的团队研究委托。默认关闭以便先升级数据库；关闭派发仍保留历史、取消、费用结算和权限检查。两个开关都不应用策略或开启交易。

源码运行将这两个值放入服务端环境文件并重启服务。Docker用户在Compose使用的`.env`中设置；根Compose和公开部署配置均明确转发这两个变量，更新镜像后需重建app容器才能生效。开启页面不自动发起研究。

### 快速开始（模板一步到位）

1. 进入「团队模拟盘」，选择「团队模板」创建方式并挑一个模板。
2. 选择模拟盘：新建（填起始现金与币种，或一键复制当前实盘持仓快照）、关联已有模拟盘，或暂不关联。默认执行连接有多个可选时下拉选定；没有连接仍可创建，之后在团队工作台配置。
3. 勾选确认后一次完成：按模板创建团队、为全部岗位配置所选连接（负责人用深度档、其余用快速档）、发布配置 v1、创建并关联模拟盘。该过程不调用模型、不发起研究、不产生费用。
4. 中断可续传：每一步幂等重试，已完成的步骤不会重复创建；明确被服务器拒绝的失败返回表单修改。
5. 落地页给出「开始使用」清单（发布版本、关联账户、岗位连接与「发起第一次研究」入口），首次研究表单预填参与岗位、负责人建议和 +24 小时截止。

### 分步流程（保留给高级用户）

1. 从空白或复制现有版本创建。模板不带模型连接、资料授权、历史业绩或交易批准。
2. 添加部门和岗位，通过拖拽或层级列表归组。岗位可以向多个主管汇报，每条说明责任范围；协作线与汇报线分开。
3. 配置各岗位的职责、预期交付、实际执行连接和工具/资料范围。空缺岗位可保留；参与运行的岗位需要完整配置。
4. 保存草稿，检查差异并发布。位置、缩放属于布局；职责、部门归属和关系属于运行配置。并发冲突保留本地变化，不覆盖另一窗口。
5. 关联模拟账户，检查已有提案和策略的交接处理。换账户先解除旧关联，再独立确认新关联；失败时显示实际未关联状态。全新空账户预选「继续原已确认规则」（此刻无实际影响）。
6. 发起研究，明确资料截止、研究期限、唯一最终负责人、参与者、工作依赖、复核、调用次数与预算。预览不发模型；确认后才创建有限委托。
7. 查看交付、反证、未知项与实际费用。采纳判断只进入既有策略预览流程；应用策略与模拟成交分别显示。

首期组织最多30岗位，单次最多6个实际执行岗位，并行1或2。一人可研究，显示自检而非独立复核。多主管引用相同工作不重复派发；不同资料版本是不同工作。付费返工默认0，授权次数作用于整个委托。

模型费按USD记账。未知用量保留估算与未知标记；仅调用次数模式需显式选择并服从现有授权。结果未知时先查询原任务，不自动重发；重新解析使用已保存原始响应，后续已授权工作仍按原预算和权限检查。

## 内置模板

| 模板 | 组织重点 | 研究依据 |
|---|---|---|
| 多空辩论投委会 | 专业分析、多空论证与风险复核 | [TradingAgents，2025修订](https://arxiv.org/abs/2412.20138) |
| 判断记忆与复盘团队 | 经理—分析员协作，记录前提修订 | [FinCon，2024](https://arxiv.org/abs/2407.06567) |
| 多视角组合研究组 | 基本面、情绪、价格与组合风险 | [AlphaAgents，2025](https://arxiv.org/abs/2508.11152) |
| 细粒度财报尽调组 | 口径、现金流、行业、估值、反证 | [Expert Investment Teams，2026](https://arxiv.org/abs/2602.23330)、[FinRobot](https://arxiv.org/abs/2405.14767) |
| 竞争假设研究组 | 独立假设按同一证据标准比较 | [ContestTrade，2025](https://arxiv.org/abs/2508.00554) |
| 矩阵专项研究团队 | 跨组共享专家，多上级但单次主责唯一 | FinRobot专业化与FinCon层级协作的产品改编 |

论文启发的是职责和协作方式，模板不复现论文回测或承诺收益。所有节点、职责与连接都可修改。

趣味模板包括「华为系·投研铁三角」「字节系·指标与反实验室」「阿里系·现金流生意参谋」「腾讯系·双工作室赛马」。它们是虚构组织梗，保留实质研究和风险核查职责，不代表公司真实组织或背书。

## 权限与历史

团队内部共享判断；不同团队的私有判断、反思和模型上下文隔离。资料通过精确版本授权，撤销或删除阻止后续使用及迟到发布。原生连接必须能证实本次任务的结构化交付和资料隔离能力；仅“已连接”不等于具备负责人能力。标准A2A属于后续范围。

团队来源授权是可用目录，岗位的资料范围是该岗位的权限上限。先给团队添加精确来源，再在需要阅读的岗位中选择授权并发布。委托只能在此范围内选择资料：共同输入需要每个接收岗位已获授权，专项输入及依赖交付需要执行者、复核者和后继接收者相应授权。预览会指出缺少权限的岗位；选择另一岗位的资料不会自动给全队扩权。跨账户历史和跨团队判断须显式授权固定输出。

一条行动可沿团队版本、委托、工作、接受的尝试、报告/论点版本、采纳事件、策略版本、信号、订单与成交追溯。缺少的旧关联会明确显示；不会按股票或时间猜配，也不会把换队前的历史改归新队。

在「资产与账户」或交易账本中，订单/成交卡提供“当时团队与判断”，可打开原委托、确切决定和当时报告版本。首页曲线下可展开“团队判断与行动”并列查看；默认只加载首批记录，可手动加载更早页。共同资料按两边判断真正引用的精确版本匹配，记录时间不冒称资料发现时间。

归档团队保留历史并停止新研究，账户规则继续或暂停由明确交接选择决定。用户暂停账户沿用现有全停语义，包括保护单。

用户后续修订、驳回、到期或排除历史论点不受原研究期限约束，记录仍归原团队和接受的尝试。新增正面内容、确认或解除排除会重新核验当前来源；撤证后仍可退役观点。用户从团队报告另建分支或编辑出的版本可继续阅读和编辑，但不能沿用原采纳直接应用策略，须形成新的精确团队产出和判断。

详细契约与验收条件见 [设计包](superpowers/specs/2026-11-12-team-paper-review.zh-CN.md)。当前实际验证与限制见 [验证记录](team-workspace-validation.md)。
