# 公网服务器部署

[English](public-deployment.md) · [本地安装](self-hosting.zh-CN.md) · [隐私说明](privacy.zh-CN.md)

吵股目前支持两种安装方式：独立的 Windows／macOS 桌面应用，以及干净的本地 Docker Compose 安装。项目不运营托管账号服务，也不提供受支持的公网服务器部署。此前的单服务器公测部署步骤已停止维护。

个人使用请按[本地安装指南](self-hosting.zh-CN.md)操作。默认 Compose 配置只将应用绑定到本机回环地址，供这台电脑访问。可选演示配置使用虚构数据，不适合保存真实账号资料。

桌面版和源码示例使用 `AUTH_MODE=local` 直接打开工作区。该模式要求回环监听并关闭代理信任，不可通过反向代理或隧道公开。Docker 保留账号验证；自行运营的远程部署必须保留 `AUTH_MODE=account` 及相应访问控制。

如果你自行修改安装配置并向其他人开放，你就是该服务的运营者，也掌握用户数据库和密钥。服务安全、备份、供应商条款及真实的隐私说明均由你负责。本地安装指南不覆盖这类运营。应用当前的数据流向和限制见[隐私说明](privacy.zh-CN.md)。
