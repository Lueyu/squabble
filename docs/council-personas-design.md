# 投研讨论室：角色与对话设计

以用户提供的概念图为依据，延续柔和纸感、绿色多头、珊瑚色质疑者和金色归纳者。实现位于实际运行目录 `D:/stock/daily-portfolio-analysis`。

## 角色系统

| 模板 | 头像 | 配色 |
| --- | --- | --- |
| 价值研究员 | 小牛 | 苔绿 |
| 成长研究员 | 小兔 | 薄荷绿 |
| 风险审视者 | 小熊 | 珊瑚 |
| 市场观察员 | 小猫 | 雾蓝 |
| 事件研究员 | 狐狸 | 杏色 |
| 宏观研究员 | 鲸鱼 | 淡紫 |
| 讨论主持人 | 猫头鹰 | 暖金 |

头像是本地 SVG，轮廓、表情与配色彼此区分。角色名称始终可见，颜色不单独承担身份含义。用户选择的 avatar 优先；旧记录无头像时按 researcher/challenger/manager 回退。头像选择、模板卡、成员列表、讨论室成员条和发言保持一致。

多空配色跟随界面语言：中文为红牛、绿熊，英文为绿牛、红熊。上表为英文默认色；中文交换 value/risk 的整套头像、气泡及卡片色板。初次加载、刷新、语言切换与深色模式都遵循这一规则。

## 聊天与交互

- 价值等研究观点左侧排列，风险模板右侧排列；主持人的消息加顶部强调线。气泡使用低饱和浅底、细边框、清晰正文，深色模式单独混色。
- 查资料进度、失败状态、引用来源、完整论据和历史修订仍可查看。
- 「追问这条观点」显示可取消的引用预览。发送时把姓名、观点摘要和用户正文组成消息，总长限制为 2000 字，不改变后端路由或承诺指定成员作答。
- 草稿正文和引用一起更新：发送失败全部保留；请求期间修改任何一项，成功回调均保留新草稿。
- 「复制观点」包括正文、结构化论据、风险、下一步与折叠详情；不包含隐藏的模型内部推理。
- 三个快捷提问填入草稿，不自动发送。输入框按内容增高，最高 160px。保留中文输入法、Enter/Shift+Enter 与未读消息行为。
- 手机成员条横向滚动；自定义长名字截断显示。正文不横向溢出，输入框保持可见。

## 验证

前端类型检查、构建、完整前端测试和作用范围内 lint。使用浏览器隔离的示例会话检查浅色、深色、手机布局、复制、快捷提问、失败保留草稿、请求期间修改正文与引用。测试接口由浏览器拦截，不写入用户的真实讨论。
