# 从研究报告到 AI 模拟实验

> **保留的高级流程。** 本文描述报告采纳、修订、实验和策略授权等保留入口。
> 当前 Web 日常使用请先看[资产、报告与策略](assets-reports-strategy.md)及[频道](channel-workbench.md)。
> 本次代码组织调整没有退役既有 API 或历史报告读取能力。

本功能连接 `/analysis`、`/council` 和 `/paper`。适用于从当前起点向未来运行的股票模拟；不连接券商真实下单，不提供历史无前视回测。

## 使用流程

1. 在每日分析的报告库选择组合日报、单股报告或期间复盘。可按主题、日期、采纳状态和历史版本筛选。打开报告可查看固定输入、数据截至时间、章节和版本。
2. 选择“讨论报告”或章节的“引用讨论”。场景、精确版本、章节和持仓资料随讨论带入；也可以加入多份报告。讨论分为本日持仓、单股、期间策略和固定候选交易复核。
3. 阶段总结可以修订引用报告：指定章节，由 AI 生成草稿或直接使用总结，然后编辑、查看差异、保存新版本。采纳是单独动作。并行修订发生冲突时另存分支，旧版及当时交易依据保留。
4. 从真实持仓选择“用当前持仓模拟”，或在模拟盘选择“从真实盘创建新实验”。核对原币现金、限制状态、持仓数量、估值、费用、滑点和基准后创建独立起点。选择实验会停止原实验的自动执行、取消旧候选并释放预留。
5. 在报告或讨论中选择“起草策略”，选择当前实验、执行团队、业务时区、日/月/自定义期间。AI 提炼结果是可编辑草稿。首次使用可先创建默认团队，再配置模型连接。
6. 填写可计算规则、价格带、仓位上限、保护止损、精确依据和可选语义条件。高级授权可约束最低现金、总敞口、单次交易、指定行业/篮子和重大事件窗口。
7. 审阅发布单后发布并启动。一个实验同时只有一份有效组合策略。新版使旧的未成交候选失效；已有持仓的保护仍独立监控。
8. 在模拟盘查看心跳、缺口、候选路线、研讨、最终拒绝或成交原因、报告章节和历史策略。日/月复盘自动归档；自定义区间可保存复盘并带入新讨论。

## 版本与授权

报告内容和输入快照不可覆盖；“最新生成”“当前采纳”“策略引用”是不同指针。普通观点更新会提示复核，不自动替换运行依据。引用被撤回、原始来源缺失或时间无效，会冻结依赖该依据的加仓规则并建立一个去重的补研讨论。

报告修订和讨论总结保留完整来源链。用新摘要包装已失效资料不能重新取得交易资格。补研中可以查看失效历史材料；它们不能成为可执行依据，须补充有效资料并发布新报告及策略。

策略绑定账户、团队版本、报告版本、生效区间、规则和额度。每日默认沿用已发布规则；也可明确授权 AI 每日仅收窄价格带、降低仓位上限、提高保护止损或暂停规则。它不能增加标的、改变方向、扩大额度、放松保护或修改触发器。每日请求有持久身份；同日失败/状态不明不自动重放，下一交易日可创建新请求。需要当日重新授权时发布新版。

从成交或报告打开历史策略时显示绑定的原实验和精确版本，只读查看不会切换当前实验或改变执行状态。团队配置更新后，草稿需要显式重新绑定并审阅版本，不能静默取得新的团队权限。

暂停或到期停止新增候选，保护性退出继续有效。关闭账户总监控会同时停止自动保护；电脑或服务关闭时也无法持续监控。

## 执行路线

| 顺序 | 条件 | 行为 |
| --- | --- | --- |
| 1 | 账户、版本、报价、市场、现金、份额或硬额度不通过 | 等待或拒绝，模型不能豁免 |
| 2 | 已授权的保护性卖出 | 快速通道，独立于正在等待的 AI/研讨任务 |
| 3 | 较大新增风险、仓位接近上限、分组敞口、事件窗口、证据分歧或流动性不足 | 多 Agent 研讨 |
| 4 | 确定、完整、在低风险授权范围内的规则 | 不调用模型，进入统一执行检查 |
| 5 | 有限语义判断 | 单 Agent 通过、等待、否决或升级 |

候选身份、方向、数量和依据固定。研讨只能审核该候选；更改交易要求重新生成候选。所有路线在成交事务中重新核对当前报价、市场、账户、版本、余额、可售数量和组合风险。原价格越界、策略被替换或来源失效，即使模型随后返回通过也不会成交。

活动候选预留现金或股份；待审、最近成交和跨股票累计新增均参与风险计算。过期、否决、切换和失败释放预留。保护性退出可以取消同股普通候选，避免慢研讨锁住保护所需份额。等待或过期后的新机会需要新报价、冷却期和新的候选身份。

## 复制与收益口径

- 复制是期初结转，不是买入，不生成虚构交易，不重复扣现金。
- 历史成本保留作参考；实验收益从复制时净值计算，已有浮盈不计为策略新收益。
- 原币现金独立记账。跨币种买入前需要明确换汇；冻结、未结算及可售状态不自动假定可用。
- 原账本随后变化会在读取实验时产生起点变化提示，不覆盖实验；报价刷新不会触发该提示。预览后源数据变化需重新核对，重复提交只创建一个实验。
- 同起点持有不动组合、SPY/QQQ 价格基准使用相同起止口径；价格基准不含分红。缺少区间起点、行情、汇率或公司行动调整时，相关收益显示未知。
- 从真实盘创建的实验默认费用 5 bps、滑点 10 bps，可在创建前修改并冻结。旧账户及沿用现金账户创建流程的新现金实验为零费用、零滑点；界面展示各自实际设定。费用和滑点进入实际模拟现金与成交记录。
- 公司行动不能完整对账时暂停并记录影响区间，不能继续展示无缺口超额收益；核对真实账本后以新起点继续实验。
- 日/月区间按策略业务时区划分；暂停或到期后仍保留最后已发布策略的时区。回撤仅反映已记录的有效净值点，并展示观测数量和数据缺口，不代表盘中或离线期间的完整最大回撤。
- 策略版本贡献列出实际成交及费用；只有存在精确起止估值时才显示该版本的区间收益，缺失边界不按比例分摊或填零。

## 首版成交模型及数据边界

使用公开报价驱动的市场价模拟，带显式手续费和滑点；报价可能延迟。统一校验交易时段、日历、报价时效、停牌状态、交易单位及可售限制。未知港股每手数量不成交；不支持港股碎股市场、部分成交、限价撮合、卖空、保证金及复杂衍生品。可获得的停牌/公司行动信息不等于完整实时交易所数据。

美国现金 T+1、香港 T+2 在模拟结算日收盘后释放；A 股当日买入次交易日可售。市场日历和假日数据超出已核实范围时等待，不猜测开放状态。

恢复后只按当前数据重新评估，记录离线缺口，不补造离线期间的历史成交。复盘区分已实现亏损待复核、执行受限与资料不足；亏损本身不被自动归类为判断错误。

## 运维与迁移

本轮只变更 Web 应用。启动顺序沿用项目现有配置；不需要启动桌面打包。已有数据库由 `createDatabase` 加载新增 `26`–`30` 迁移。迁移按完整 SQL 文件执行，以保留触发器和事务语义；Docker 和 CI 已包含文件。新安装 `01_schema.sql` 含完整追加定义，可用 `node scripts/db/sync-fresh-schema.cjs` 同步。

历史报告仅导入仍存在的原始内容；被覆盖的日报无法恢复，未知时间和快照不会用当前资料补造。所有接口按登录用户隔离；本地 Agent 的重试通过任务/内容身份去重。

关键接口：`/api/research-documents`（版本/修订/采纳），`/api/council`（场景/引用/分支），`/api/strategy-mandates`（草稿/发布/状态），`/api/paper/experiments`（预览/创建/切换/复盘）。具体 API 字段以 `shared/` 类型和对应控制器为准；MCP 账户语义见 [mcp-paper-accounts.md](./mcp-paper-accounts.md)。

实施范围与验证记录见 [research-strategy-loop-validation.md](./research-strategy-loop-validation.md)。
