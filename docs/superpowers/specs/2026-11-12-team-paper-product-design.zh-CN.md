## P01. 页面与导航边界

桌面保留「投资总览、我的股友、投资日报、研究室、资产与账户、数据中心、记忆、运行分析、模型与设置」顺序，股友之后插入团队。仅原资产与账本改名资产与账户，不替换股友。手机原快捷导航保留，团队加入更多。

| 页面/入口 | 路径与身份 | 返回规则 |
|---|---|---|
| 首页 | 既有 `/` | 保留图表选择、区间、滚动位置 |
| 我的股友 | 既有 `/paper` 及 `/paper/:accountId` | 保留旧入口；其中查看持仓转到统一资产页 |
| 团队列表 | 拟新增 `/teams` | 记住搜索、过滤与滚动位置 |
| 团队画布 | 拟新增 `/teams/:id` | 返回团队列表；分组/连线/分工/发布是同页状态 |
| 持仓与现金 | 既有 `/holdings`，新增账户参数 | URL 明确账户；无参数的旧链接默认实仓并规范化 |
| 交易账本 | 既有 `/transactions`，新增账户参数 | 同一账户；从订单返回保留筛选和账户 |
| 关注列表 | 既有 `/watchlist`，工作区范围 | 明示非当前账户持仓；保存来源账户返回位置 |
| 导入与对账 | 既有 `/import`，仅实仓 | 模拟盘隐藏入口；直达不把模拟账户变成导入目标 |

子状态支持恢复，未保存输入不放 URL。先验证深链归属，无效目标不任选账户代替。返回上下文包含账户、来源页、筛选、滚动位置，返回地址限应用内。

## P02. 首页原区块与账户表现

保留页头问候/日期/新建模拟仓、账户表现图、我的账户、我的真实资产/今天的投资日报、底部与股友聊策略。新建模拟仓仍走原流程，不强制建队；真实资产到 `accountId=real`，日报/访谈不变。

复用金额/收益率、区间、比较设置、估值口径、图例及空态。图例只切显示；曲线详情和卡片均到对应资产页，返回恢复图表状态。创建、改名、选择不制造观察或触发研究。

| 账户卡字段 | 展示口径 | 空值/限制 |
|---|---|---|
| 名称与类型 | 实仓；或模拟盘账户名＋所属团队名 | 未绑定旧盘显示「未绑定团队」，仍可查看资产 |
| 当前估值 | 原币/既有统一基准币种、估值时间和口径 | 不足以估值显示「暂无法完整估值」；不可把缺值当 0 |
| 收益/起点 | 既有可信观察区间，与曲线口径一致 | 初始化单点显示「历史不足」，不写累计收益 0% |
| 状态 | 研究状态与模拟执行状态分开 | 没有记录写「尚未发起研究」；未知不写失败 |
| 主操作 | 查看资产 | 始终指向该卡账户，独立于图例当前选中集合 |
| 团队入口 | 有绑定时进入团队画布 | 未绑定提供关联入口，不能虚构团队配置 |

实仓与模拟盘分别计算；不同起点/现金流/覆盖不称同条件胜负。缺失断线，当前估值不冒充历史净值；复制配置不复制成绩。

## P03. 统一账户上下文与跨页行为

原标题区加账户选择器：实仓在前，再列可访问模拟账户，标类型、名称、团队/未绑定。URL 优先于记忆；仅旧无参数链接默认实仓，无效 ID 报错。团队与账户归档分别解释。

切换先显示目标身份与加载态，移除旧账户可交互数据；旧请求晚到不能覆盖新账户。失败显示目标名，可重试或另选，不自动回实仓。返回恢复该账户筛选/排序，首次用原默认。

交易账本继承账户，模拟记录有标识。关注页说明「工作区关注列表，非当前账户持仓」，可返回原账户。模拟隐藏导入；直达模拟导入参数显示不支持及返回入口，明确选择实仓后才可导入。

研究、交付、策略、订单保留来源账户与位置，详情展示自身真实归属；不一致须明确跳转，不能重归属历史。后退、刷新、分享定位同一对象；分享不授权。

## P04. 资产表、操作差异与数字可信度

保留市场/行情时间/数量/市值/浮盈摘要、待复核提示、市场筛选、搜索分组、桌面表、币种小计/现金、手机卡。实仓保留刷新/复制/添加/编辑/导入/分析；模拟只读账本，组合到原 `/paper/:accountId/strategies`。

| 列/数值 | 数据含义与格式 | 模拟盘展示要求 |
|---|---|---|
| 证券/市场 | 名称、代码、市场标签；代码用于身份 | 原记录缺名称时保留代码，不猜证券 |
| 数量 | 账本持仓数量，按市场/资产精度 | 不可手工编辑；0 是已确认数量，未知另显示 |
| 平均成本/币种 | 该账户账本成本与原币种 | 缺成本显示「未记录」，不倒推成本 |
| 当前价格 | 有有效来源与时点的估值价格 | 不是成交承诺；缺价格显示原因 |
| 市值/浮盈 | 有完整数量、价格、成本等条件才计算 | 不支持的列显示缺口，不填示例数或 0 |
| 汇总/现金 | 按币种分组；跨币种合计须有汇率与时间 | 单独列该盘现金，不借用实仓现金 |
| 订单/成交 | 账户内真实状态、数量、价格、时间 | 等待、部分成交、已成交、拒绝分别显示 |

刷新只读，不造历史观察。部分成功说明缺失范围及总额覆盖；未知排序在后。展示舍入不改计算；沿用盈亏颜色并配文字方向。

## P05. 团队列表、新建与旧盘关联

页头「团队模拟盘」＋「新建团队」。支持名称搜索和全部/已发布/有草稿/未关联过滤，默认最近编辑排序。卡片列名称、账户、版本/草稿、岗位/连接数、研究及执行状态；主操作配置团队，次操作查看资产/复制。

| 新建字段 | 默认/必填 | 何时可用及验证 |
|---|---|---|
| 团队名称 | 空，必填；建议 1—60 字符 | 去首尾空格；重名提示区分，不把名称当身份 |
| 头像 | 系统默认图案，可改 | 不影响岗位、执行器或历史身份 |
| 创建方式 | 从空白创建 | 可选复制现有配置，明确来源版本 |
| 关联账户 | 默认未选择 | 可选择可访问模拟盘，或进入既有建盘流程 |
| 说明 | 空，选填；建议最多 500 字符 | 描述团队目标，不自动成为研究委托 |

名称有效即可创建草稿，不要求成员或账户；未关联提示研究前须关联。进入原建盘流程保留输入，取消回草稿。选已有团队的盘须交接，不抢占。

复制组织、职责、关系、布局，连接重新核权；不复制密钥、历史、批准或表现。副本默认“原名 副本”、未关联、未发布。旧盘仍可查看和用既有策略，不把旧判断算作新团队。首轮无快捷删除；归档预览未完成事项，停止后续新研究，不级联删除账本或暂停账户。归档团队只读，可复制配置为新团队，不隐式恢复。

## P06. 团队画布页面布局与操作入口

页头列团队、账户/未关联、发布版本/草稿；按钮保存草稿、检查并发布、发起研究、查看资产、更多。研究与执行状态分开。存在草稿时研究仍明确使用已发布版本。

左侧工具箱/层级列表，中间画布，右侧选中属性，无选中则团队概要；下方可折叠当前委托/待复核/近期决定。点节点只开属性，点记录进既有详情并保留返回位置。

| 按钮 | 可用条件 | 结果 |
|---|---|---|
| 保存草稿 | 有本地变更且团队编辑权限有效 | 保存可不完整的语义草稿；不发布；未绑定账户也可保存 |
| 检查并发布 | 有已保存草稿或首版待发布 | 打开结构、能力、差异与影响预览 |
| 发起研究 | 有已发布版本、有效账户及可用参与方案 | 打开委托表单；不能因按钮点击直接收费 |
| 查看资产 | 有可访问关联账户 | 到对应 `/holdings`；未关联显示关联操作 |
| 添加部门/岗位 | 可编辑当前草稿 | 建立节点并聚焦名称；不创建真实执行调用 |
| 查看历史 | 有历史版本/任务；无记录也可打开空态 | 只读历史，明确当前版本与当时版本 |

空画布可添加或复制，不预置三人；示例角色均可改名、删除、换连接。一人可研究并交用户审阅，模型侧标「自检／非独立复核」。折叠后保留搜索、定位及错误数。

## P07. 部门、岗位与执行连接的独立配置

| 对象字段 | 默认与规则 | 运行含义 |
|---|---|---|
| 部门名称、说明、父部门 | 新部门待命名；父部门为当前选中部门或根层 | 归组与职责边界；部门本身不是模型或执行器 |
| 岗位名称、职责范围 | 新岗位待命名；职责初始空 | 发布参与运行的岗位需写清职责，不能以头像替代 |
| 预期交付 | 初始空，可用文字描述 | 作为研究分工建议，本次委托仍需确认 |
| 连接与模型设置 | 默认未配置 | 岗位保留；选连接后才有执行能力，不自动获得工具权限 |
| 参与状态 | 新岗位为待配置 | 未配置岗位可留草稿；可标“不参与当前运行”保留组织位置 |
| 默认负责人建议 | 默认未指定，可选一个建议岗位 | 仅预填本次委托；每次仍确认唯一最终负责人 |

部门可嵌套、移动、折叠、解散，不能放进自身/后代。解散预览后默认子节点移到上级并保留关系；连内容删除是独立选项。单一视觉归组不限制跨部门关系。

删岗位预览关系、草稿分工及负责人影响，只改草稿；历史保留原岗位/连接。空缺在节点、列表、发布检查均有文字提示。

## P08. 多线汇报、责任范围与协作关系

创建先选类型。实线从汇报岗位指向主管，逐线标责任范围，允许多主管。虚线标委托/复核和方向；双向各列职责，不用无箭头线含混表示。

| 关系字段 | 默认/必填 | 校验与提示 |
|---|---|---|
| 类型 | 显式选择汇报/委托/复核 | 编辑类型属于语义变化 |
| 起点、终点 | 来自所选节点，可改 | 只能引用本团队当前草稿中的岗位 |
| 责任范围 | 汇报必填，初始空 | 相同起终点允许不同范围，不误判成重复 |
| 协作说明/交付建议 | 初始空；运行前需明确任务 | 约定不是实际委托或付费调用 |
| 方向 | 按选择顺序，预览文字描述 | 可反转；需要双向时逐向确认 |

建议发布阻止自汇报、同语义重复和责任环，定位错误但允许存草稿；多根、多主管、跨组合法。协作环不自动派发，任何关系不叠加权限/预算。

拖线显示候选，松手确认属性，Esc 取消。点线可改范围/方向/删除；重叠线可从列表选。复制节点/边不复制调用授权。

## P09. 内置模型、原生助手与成员状态

职责与连接分别设置；内置/原生选项列名称、能力、模型来源、状态、检查时间。原生具备本次统筹能力即可任负责人；未核实说明缺项，不能按类别统一禁用。

| 状态 | 用户看到的含义 | 可用动作 |
|---|---|---|
| 未配置 | 岗位未选执行器 | 选择连接；可保存草稿 |
| 未连接/登录失效 | 当前不能建立运行 | 去现有连接管理；保留岗位输入 |
| 可用 | 已检查能力满足当前用途 | 可进入发布/分工检查，不代表已执行 |
| 繁忙 | 已有任务或资源不可立即用 | 稍后发起；只有持久队列能力已支持才提供排队 |
| 模型未知 | 未取得可验证模型标识 | 显示未知；按已知能力判断，不冒充指定模型 |
| 能力不支持/未核实 | 不满足该次职责或缺证据 | 展示具体缺项，换连接或缩小本次任务 |

共用连接显示复用/并发限制，不称两个独立模型。检查只读、不收费；发现不等于授权。密钥仅在原设置管理；A2A 无可执行占位。

## P10. 画布选择、拖拽、撤销和等价操作

点节点/边选中，空白清除，Shift 加选，空白拖动框选。拖节点默认改位置，命中部门才显示加入提示并松手归组；拖部门携子节点，跨组线不变。Esc 取消，完成动作才入撤销栈。

工具栏含缩放、适配全部（默认）、定位、撤销/重做、关系过滤；不改语义。列表“移至部门”、属性移动菜单、关系表新增可替代拖拽；搜索可展开定位折叠内节点。

| 键盘/菜单 | 本轮建议默认行为 | 边界 |
|---|---|---|
| Tab / Shift+Tab | 顺序访问工具、列表、属性和操作 | 焦点可见；不要求遍历每条装饰线 |
| Enter / Space | 选择聚焦节点或打开属性 | 输入框中保持原编辑语义 |
| 方向键 / Shift+方向键 | 选中节点小步/大步移动 | 建议 8/40 像素，仅布局变化 |
| Delete / Backspace | 打开删除影响确认 | 文本框内只编辑文字，不删节点 |
| Ctrl/Cmd+Z、Shift+Z | 撤销/重做本次未发布编辑 | 不撤销已开始任务或已发布历史 |
| Ctrl/Cmd+S | 保存草稿并显示结果 | 离线提示仅本地保留，不声称服务器成功 |

归组撤销恢复位置和父部门，删除撤销恢复节点/边。发布后恢复旧配置须复制成草稿再发布，不倒改历史；过滤不删除对象。

## P11. 布局、语义草稿、离线与并发保存

位置、视口、折叠、名称/头像属展示；归组、职责、关系、连接、工具范围属运行语义。分别显示布局已保存/运行配置有草稿；改名不改历史身份。编辑工具范围不能新增授权。

建议本地即时暂存、布局停止编辑后自动保存、语义显式保存。无回执不称已保存，布局不暗发语义。离开未保存内容提供保存并离开/放弃/继续；保存失败留原页。

并发比较修订，冲突保留本地并列差异，用户选服务器版或重新应用本地变化；不后写覆盖，不以布局合并绕过语义冲突。发布再查版本/绑定，旧预览失效。

离线可本地编辑/看缓存并标时间，不能发布、绑定、发起。联网先对账，不重发未知请求。草稿恢复标团队/时间；退出按会话策略清理私有缓存。

## P12. 检查发布、关联账户与交接

同页发布预览列基准→候选版本、节点/关系差异、连接、账户、运行影响；阻断可定位，提醒有解释。未保存先保存，再生成预览。

预览有效期建议 15 分钟，界面显示剩余时间；依赖版本、授权或绑定变化可提前使其失效。过期后保留输入并重新检查，不直接重放旧确认。

发布须名称有效、参与岗位职责/连接明确、结构通过、绑定无冲突、草稿/授权/预览未过期。空缺展示岗位标不参与运行。无账户可发布组织配置为待审默认，持续标未关联、禁止研究；绑定后重验。

| 预览操作 | 条件 | 可见结果 |
|---|---|---|
| 返回修改 | 始终可用 | 保留草稿和选中对象，关闭预览 |
| 发布配置版本 | 无阻断项且用户确认差异 | 成功显示新版本及适用后续委托；不启动研究/交易 |
| 预览关联/更换账户 | 有候选可访问模拟账户 | 列旧、新绑定及未完成任务/提案/策略影响 |
| 确认交接 | 对受影响事项逐项有明确选择 | 新运行归属生效，旧任务历史仍属于原快照 |

交接不静默替换：列运行研究、待复核/待应用提案、确认组合、执行状态；旧任务不迁盘。组合继续/暂停须用户选择，全部暂停包含保护单；改策略回现有组合预览，发布不夹带应用。

同一账户更换团队一次提交。一个团队从旧账户改到另一个账户则分两步：先确认解除旧关联及旧盘规则如何处理，再独立确认新关联与新盘规则。第二步失败时明确显示团队暂未关联，提供继续关联入口；不假称整次换盘已经成功，不自动恢复旧盘状态。

等待发布回执禁止重复提交；未知先核对，不重复建版。冲突重验、失败保草稿。绑定失败不称接管，成功后导航/资产/委托一致更新。

## P13. 手动研究委托表单与固定资料

团队页表单→同页分工预览→已有研究室记录。有草稿仍明确本次使用已发布 vN，可回发布，不混用版本。

| 字段 | 默认值/要求 | 可用与校验 |
|---|---|---|
| 目标账户 | 当前绑定账户，明确名称与模拟标签 | 不允许只凭团队名推断；换账户需回关联/独立委托流程 |
| 研究问题 | 空，必填 | 写清要判断的问题；建议 1—2000 字符 |
| 目标与交付 | 空，必填 | 如结论、证据、反对理由、适用条件；不是预先确定买卖 |
| 引用资料 | 默认不额外共享其他团队私有资料 | 显式选择有权使用的资料及精确版本 |
| 资料截止 | 默认本次预览生成时间，显示时区 | 历史回看可选择更早截止；不得纳入之后发布资料 |
| 最终负责人 | 有可用默认建议则预填，否则未选择 | 必须一个；内置或原生能力按本次用途检查 |
| 参与岗位/复核 | 按关系提出建议，用户确认 | 一人可自检并由用户复核，明确非独立复核，不强求另一模型 |
| 调用与预算限制 | 取现有可用默认并显示来源；无默认则待填写 | 调用数/费用估计与实际限制分开；未知费用不能当免费 |
| 预算模式 | 默认使用当前账户允许的费用＋调用次数限制 | 仅当前授权允许时可明确选“只限制调用次数”；须提示原生外部费用可能未知，金额空值不是免费 |
| 调用次数上限 | 取可用现有配置，无默认则待填写 | 正整数，研究、复核、付费修订共同消耗；一次岗位工作可能有多个调用 |
| 研究截止时间 | 取现有允许时限，无默认则待填写 | 显示本地时区；截止后不派发新调用，已派发费用仍记录；与资料截止分开 |

预览需问题、交付、账户、资料有效；首轮用职责/表单产生可编辑分工，不收费。未来 AI 拟分工须独立披露费用并由用户触发。

固定来源版本、内容身份、截止时点；新资料只提示。改输入/账户/参与者/权限/预算使预览失效。停用、删除、撤权阻断新用及迟到接受；历史引用不换成新版。

## P14. 分工预览、唯一最终负责人和有界运行

预览列账户、版本、截止、唯一最终负责人；逐岗位列实际连接/模型、范围、固定输入、交付、依赖、复核、调用/预算。其他主管是参与/协作；调整本次分工不改长期组织。

确认发起须负责人唯一，输入、交付、复核、能力、预算完整；未参与空缺不阻断，参与的失效连接须修复/移除。能力缺项具体解释，不按内置/原生类别禁用。最终再验版本/授权/预算。

待审默认：单次最多 6 个实际执行岗位，含负责人/实际复核，纯引用主管不计；并行默认 1、最多 2 且服从连接能力。组织可更大，本次选子集，超限不默默丢岗位。同连接多岗位、一个岗位多交付/返工均列真实工作与调用成本；岗位数不等于调用预算。一人标自检/非独立复核，交用户审阅。

同一岗位同一交付多方引用，不重复派发；不同范围在预览拆清。负责人记录主管冲突的采用/舍弃/待澄清理由。超范围、调用、权限或预算回用户确认，不合并主管预算绕限。

建议默认不追加付费修订；预览可授权次数/预算上限，范围内才继续，返工保留尝试/版本。依赖须可终止，协作环不作执行循环。一次手动授权后的内部编排不等于自动发起新委托。

## P15. 交付、复核、提案和历史引用

委托列状态、负责人、连接、团队/资料版本、时间、费用、未完成项。交付→原会话/报告，采纳→原策略流程，回执→对应账户订单。缺关联的旧记录标归属未知。

| 阶段 | 文案及含义 | 后续操作 |
|---|---|---|
| 等待/运行 | 已有任务身份，尚未取得最终交付 | 查看进度；请求取消；不重复发起 |
| 已返回、待验收 | 提供方返回内容，尚未通过本地结构检查 | 查看原交付与具体缺项 |
| 结构验收通过 | 格式、引用身份与要求齐备 | 不代表事实正确；进入内容复核 |
| 内容复核 | 依据、反证、局限和适用范围可审阅 | 通过、要求修订、拒绝或暂缓，记录理由 |
| 用户采用 | 接受该版本为后续策略依据 | 进入既有策略预览；并非已应用 |
| 策略已应用 | 已确认规则/组合生效 | 等待条件或查看模拟执行状态；并非成交 |
| 模拟成交 | 有具体订单/成交账本回执 | 显示数量、价格、时间、账户与部分成交情况 |

交付有稳定身份/版本，多主管共同引用；历史保留当时岗位/连接/输入。再解析标使用已保存结果；重跑明确新调用/费用。未填理由写未记录，等待不等于无任务。

## P16. 配置、规则与授权变化的影响

以下为已批准的细粒度影响规则，保留策略确认、撤权与账户暂停边界；实际验证见单独记录。

| 变化 | 草稿/新任务 | 已开始任务与既有策略 |
|---|---|---|
| 名称、头像、布局 | 保存展示；不需重新授权 | 不改变任务、来源或模拟执行 |
| 部门、职责、研究连接、协作 | 发布新版本，后续委托使用 | 旧任务按快照结算；可另行请求取消；已确认策略不因改成员停机 |
| 研究预算收紧 | 阻止新的超限调用，解释受影响分工 | 已派发调用与未知费用继续记账；不据此暂停保护单 |
| 复核负责人变化 | 新待审事项按新分配 | 受影响的未完成复核重新指派；已完成批准保留其当时依据 |
| 主责团队/账户绑定变化 | 明确交接，待审/待应用提案重新复核 | 旧任务不迁账户；既有组合继续或暂停由交接预览明确选择 |
| 策略、风险边界变化 | 到现有组合预览/确认，重验候选 | 团队发布不能直接改订单规则或免除来源校验 |
| 来源/工具授权撤销 | 阻断相关新的读取、派发和依赖执行 | 禁止迟到发布/新采纳被撤销来源；无关账户不扩大停止 |
| 用户停止全部模拟执行 | 使用现有账户暂停流程 | 明确包含保护单；恢复仍走现有必要确认流程 |

发布不等于撤权；撤销/删除/风险收紧优先于旧快照继续结算，迟到结算不等于允许发布。底层能力不足须列差距审核，不伪称细粒度已实现。

## P17. 空载、失败、未知与恢复文案

| 场景 | 必须呈现 | 恢复入口与禁止行为 |
|---|---|---|
| 没有团队 | 创建/复制入口、简短用途 | 不强制把已有模拟账户迁移成示例团队 |
| 旧盘未绑定 | 原账户名、未绑定团队、历史可读 | 可关联；不阻断原账户查看或捏造团队绩效 |
| 无持仓/无历史 | 已确认空持仓与历史不足分别显示 | 空数组不等于账户加载失败；初始化点不算收益 |
| 离线/加载失败 | 对象名、缓存时间、真实错误状态 | 重试读取；不能先显示别盘内容填空 |
| 任务已排队 | 已存在任务、等待原因 | 取消请求/查看状态；不能写尚无记录 |
| 助手静默/掉线 | 最近可见活动，完成情况未知 | 检查原任务；不凭无心跳断言失败 |
| 取消处理中 | 已请求，尚未确认停止 | 保留可能费用；不立即释放可能占用或允许自动重跑 |
| 结果未知/响应丢失 | 明确未知及待核对内容 | 先查原请求回执，不换连接自动重发 |
| 返回格式不符 | 原结果保留、具体结构缺项 | 支持时复验原结果；新研究须另行确认 |
| 费用未知 | 已知、估计、未知分别列 | 未上报用量不显示免费；迟到用量可补记 |
| 无权/已归档 | 归档可读状态或安全的不可访问原因 | 不泄漏无权对象内容；不静默换账户 |
| 发布冲突/过期 | 当前版本与本地草稿差异 | 重新检查；保留本地改动，不自动覆盖 |

读取不触发研究。错误定位字段/连接/来源/账户；重试明确是读取、保存、解析或新调用，未知调用不提供含混的一键重跑。

## P18. 手机、无障碍与体验规模

手机保留首页/图表/账户卡及原持仓卡；账户选择可见，长名两行。团队筛选收入菜单；默认组织列表，可展开、改属性、移组、添加多主管及编辑范围/方向，无需精确拉线。

图形视图可缩放/平移，点节点开底部属性；归组仍预览目标，不误把滚动当编辑。分工/发布全屏，按钮不遮错误，返回保输入；不省略账户、预算、资料或负责人。

关系用线型/箭头/文字；输入有标签，禁用有原因，错误可定位。状态宣告不抢焦点，关弹层还原焦点；触屏目标建议 44 像素，尊重减少动画。

已批准规模默认：首期每团队最多 30 岗位、部门另计；每次研究最多 6 个实际执行岗位，并行默认 1、最多 2。矩阵组织不受单次 6 人截断，示例三人不构成限制；这些是产品上限，不代表性能基准。

达到 30 岗位上限时阻止新增/复制岗位并解释，已有草稿仍可编辑、保存、删除、恢复；批量复制预检查，超限整批返回，不截断节点。验收覆盖嵌套、多线、选择、定位、折叠、拖动、撤销、保存、手机列表；不承诺未测帧率。部门深度和关系数如需限制另审，不能借运行适配限制暗改自由度。

| P16 | 有运行任务、策略/保护单 | 改连接再撤销来源 | 普通配置不暗停保护单；撤权阻断相关新用/迟到发布 |

| P18 | 手机嵌套/多线/发布阻断 | 列表或键盘编辑发布 | 等价语义可编辑；关键确认不省略，阻断可定位 |
