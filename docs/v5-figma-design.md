## 视觉和布局

沿用 Squabble 的低饱和绿色、暖白背景与原动物身份。主要颜色引用现有变量：`color/ink #172B26`、`color/muted #6B7973`、`color/line #E4EAE5`、`color/soft #F5F7F4`、`color/brand #26765C`、`color/brandSoft #EAF3EC`。蓝、紫、琥珀只用于来源类别或状态，不能仅用颜色区分成功和失败。

桌面稿宽 1440，原主导航 224，顶部位置栏 72；常规主内容左右边距 32，内容宽 1152。标题 28，正文 14–15，辅助信息 12–13；卡片圆角 16，输入与按钮圆角 8–10，间距主要为 8/12/16/24/32。代码继续复用现有字体和设计系统，Figma 中文字体为 Noto Sans SC。

研究室保留主导航；内部侧栏 240，主体剩余 976，内容内边距 40，主要内容最大约 896；输入框宽 856。消息流滚动，输入框固定在研究工作区底部，且不覆盖最后一条消息。宽度不足时收起内部侧栏，不压成三列窄栏。手机按 390 × 844 设计，边距 16；主导航和历史/策略分别用明确的菜单按钮。抽屉关闭恢复原会话、筛选和滚动位置。

## 我的股友与日报

股友卡头只显示动物头像、唯一账户名、短风格标签。净值为唯一大数字，其下是一行收益信息，再一行状态与策略数。主操作是“查看账户”；暂停/恢复为次操作；删除在卡头的轻量操作区直接可达，不必进入详情。删除仍先显示名称、影响与确认；执行后保留现有后端所定义的历史语义。

移除“我的策略库”“一起聊出策略”“在总览看多仓曲线”以及重复账户名、起点、对比入口等挤占卡片的内容。卡片外不新增原后端不支持的筛选。桌面三列，较窄两列，手机一列；标题允许合理换行，金额不与操作区争夺空间。

日报每条行动固定用动物头像开头，正文为“谁 → 做了什么 → 为什么”，结果标签放右侧。没有 `companionId` 时仍使用稳定的动物 fallback，不能因为消息角色是 user 就变成人形图标。无交易是一种有明确原因的结果；缺失原因显示未提供，不编造“保持耐心”。

## 研究室

- 侧栏固定“新对话”，下方两个 tabs：聊天记录 / 策略库。策略和访谈在本页打开，不通过卡片跳出研究室。历史深链接保持兼容。
- 输入 `/` 打开可搜索的技能菜单：命令、中文用途、一句说明。支持键盘选择、Esc 关闭、删除所选标签；选技能后保留用户原问题。稿展示 `/strategy /challenge /financials /peers`，`/valuation` 和附件适配的其他金融技能在同一目录滚动展示。
- `/strategy` 开始多轮访谈，一轮聚焦一个关键问题；用户可以选项回答，也可自由输入。持续展示“已确认 / 待确认”，明确目标模拟账户，不要求一次写完整规则。
- 草案保存、验证预览、确认采纳是不同状态。稿 `171:1239` 展示选择目标账户与“预览执行”；确认采纳后的动作复用既有流程与回执，不因生成草稿或切换技能自动启用策略。
- 消息主体首先给出公开研究结论，再显示成员公开摘要。活动组直接可见：成员、实际已加载 Skill、真实工具动作/状态；耗时、来源版本与更多细节展开查看。
- 不展示或伪造模型隐藏思维链、内部 prompt、stderr。没有工具 journal 的模型只写“已加载技能 / 使用现有快照”，不能把快照写成刚调用了工具。所有成功、失败、等待文案来自持久化事件。
- 点击资料引用打开当前证据与版本；来源已删除时保留可解释的引用标记，并停止用于新的研究。

## 数据中心

三个平级 tabs：资料库 / 网站订阅 / 金融数据源。页标题、tab 行与内容左边界保持一致。所有配置在本页完成，不再做一组去设置或其他页面的链接。

资料库桌面为列表 770 + 24 间隔 + 358 预览；展示类型、标题、来源、更新时间与状态。选中行原地显示内容、原文、版本；“在研究室使用”带资料身份进入会话。手机选择资料后打开详情抽屉/页，顶部明确“返回资料库”，恢复原列表状态。文件类型包括文本、HTML、PPTX、图片；图片保存成功与 OCR 完成分开显示，首版未 OCR 不能写“已解析”。

导入弹窗包含网页链接和本地文件，定期同步是可选项。校验错误紧邻输入，保留用户输入；上传过程中显示真实进度/状态并禁止重复提交，失败可重试，成功后选中新资料。原文件和提取文本分开，空文本、解析失败都可继续查看和下载原件。

网站订阅左侧 330 列表，右侧 798 详情：地址、周期、授权方式、最后成功时间、下次同步、最近结果。支持无需登录、Cookie、Bearer、Basic 等服务实际允许的方式。授权只保存在后端加密凭据中，不出现在资料正文、记忆或模型上下文。省略凭据时保留旧值，清除凭据必须是明确动作。

设计示例网站已按用户给出的地址标为 **Pickalphas / https://pickalphas.com/**；样稿的篇数、文章和登录错误全部是演示，并不表示连接已被验证。401/403、登录页、超时、网络失败、空内容分别说明；授权过期时保留旧资料、停止无意义重试、提供“更新授权 / 保存并重试”。同步中、无变化、成功新增版本、部分失败、暂停各有独立文字状态。具体抓取能力与限制见数据中心实施契约。

金融数据源左侧 380 供应商列表，右侧 748 配置；包含公共行情、SEC EDGAR、Finnhub、Alpha Vantage。显示能力、已配置/未配置、启停与上次实际测试结果。保存配置和测试连接分开；API key 隐藏，用户可替换或清除；服务只开放 allowlist 范围。Alpha Vantage 的日终数据明确标记；缓存和样例数据都保留来源与时间，不装成实时成交行情。设置页移走金融数据配置，并保留原 Finnhub 密钥。

## 导航与可点击覆盖

已连线 104 个可点击入口：原型导览、V5 一级菜单、资料三 tabs、导入打开/关闭、研究聊天/策略 tab、slash 策略入口、草案查看/继续修改和手机退出。V4 未改变的资产、记忆、模型页面由已有原型链接承接，V5 不重画无关流程。部分输入、网络测试和真实交易按钮为静态设计状态；它们的可执行验收在应用中完成，不把 Figma 示意当实际操作。

产品实现必须继续沿用已有明确返回语义：详情返回来源列表，模态关闭返回原页面，访谈退出回研究会话。不要把原型导览的返回方式直接照搬为产品页面返回逻辑。一级菜单展开二级设置时，一级项样式保持稳定。
