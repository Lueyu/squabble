# 组织编辑器可用性修复方案（已批准）

2026-11-17批准完整实施、PR合入main及本地部署。问题依据为当前运行页的桌面/手机观察与源码核对。

## 范围与顺序

1. 组织页专用工作区：压缩标题和修订信息，256px目录、弹性画布、320px属性；窄屏使用列表和属性对话框。目录紧凑单行、单一滚动区；研究分工使用统一主题和局部样式。
2. 补齐交互：显式view=canvas/list；可点击/键盘指派股友并共用拖放命令；关系属性与关系列表一致；校验问题直达配置对象。选择与布局操作不发起研究或授予权限。
3. 可读性：默认汇报线、按选中岗位查看关系、关系标签按需显示；合并缩放工具并显示比例、100%与适应全部。新模板使用部门内相对坐标；不转换已有用户布局。
4. 状态：主状态表达是否保存，技术修订折叠；发布、账户关联、研究仍为独立步骤；分工设置与只读服务端结构预览区分。

## 验收

- 390×844、1440×900、1920×1080及中英文、深浅主题；长名称、空团队、多岗位和部门嵌套。
- 实际点击视图切换、列表编辑/抽屉、指派/不可用反馈、关系表单、撤销/重做和保存；使用虚构隔离数据。
- 针对性行为测试、完整客户端/服务端/本地助手测试、lint/typecheck、build:web、context和architecture检查；PR必需的三项CI通过后合并。
- 本地更新保留原数据库、密钥与持久资料，停机后最终备份并恢复验证；健康及已有数据只读检查，不以付费研究作部署测试。

## 架构核对

五张既有架构图的模块归属和研究/授权/模拟执行数据流仍有效。新增的是团队配置页的交互与呈现，复用已有Team草稿/版本、roster身份和确认路径；不新增后端权限、迁移或执行入口。团队组织/蓝图前置实现的结构变化另见architecture第6节。
