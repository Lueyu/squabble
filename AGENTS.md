# Working in Squabble

Start with the repository-owned [Squabble contributor skill](.agents/skills/squabble-contributor/SKILL.md).
It is the canonical router for workspace inspection, code entrypoints, contracts,
test selection and deployment/recovery instructions. Read the references relevant
to the task; do not treat an installed copy or a historical proposal as current
source authority.

For a first code tour, use [代码阅读指南](docs/code-reading.zh-CN.md).
Current workflows and historical documents are separated in the
[documentation index](docs/README.md). Follow [CONTRIBUTING.md](CONTRIBUTING.md)
for the current development phase and PR checks.
